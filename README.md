# flaunt-site

The public website of Flaunt Technologies L.L.C-FZ: https://flaunt.ae

One static page, `public/index.html`, with no build step and no dependencies beyond Google Fonts.
Deployed by Cloudflare Pages from the `main` branch; every commit to `main` goes live.

No secrets live here. Contact addresses on the page change by editing the HTML.
